Практична робота №12
Прсунута робота з файлами в Java

У рамках цієї роботи Вам потрібно відточити практичні навички стосовно роботи з файлами у Java. Код має бути опублікований (закомічений) до вашого репозиторію на GitHub. Для кожного завдання пропонуються створити окремий Java файл (клас) де ви і маєте виконувати відповідне завдання.
Результатом виконання має бути посилання на  Ваш репозиторій, який ви додасте до Google Classroom. Також надайте знімки з екрану результатів виконання ваших програм (бажано з різними вхідними даними). Окремо закріплені файли з кодом НЕ приймаються.


Завдання

Дана робота має базуватися на практичній роботі №11. Необхідно замінити використання FileReader/FileWriter на BufferedReader/BufferedWriter. Також потрібно замінити звичайний обробник виключень з try-catch-finaly на try-with-resources.
Окрім цього, необхідно додати наступне:
Додати можливість додавати декілька рядків одночасно до файлу.
Додати покажчик поточного номеру рядка - з лівої сторони від тексту, що міститься в файлу. Його потрібно виводити як при читанні файлу, так і при запису.
Додати моливість задавати номери рядків початку та кінця диапазону, що потрібно виводити (наприклад, з 3 по 8 рядок) - додатковий пункт меню.
* Додати можливість записувати в файл в обраний рядок - наприклад, в файлі 4 рядки, ви обираєте 3 - і додаєте в 3 рядок. Текст, що було пізніше - переміщується в самий кінець
НЕ ДОЗВОЛЯЄТЬСЯ використовувати інші структури даних для зберігання, окрім масивів. Також не можна використовувати StringBuilder і регулярні вирази.
